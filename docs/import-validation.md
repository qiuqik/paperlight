# 导入流程验证（2026-09-30）

以下 arXiv 链接导入数据是历史验证记录。新链接导入入口及服务接口现已停用；旧文档继续可读。PDF 替代路径和 MinerU 对照见 [MinerU PDF 解析试验](mineru-evaluation.md)。

使用正式 parser 容器和 arXiv 官方页面测试，解析输出写入临时目录后统计；PDF 回退使用相同容器中的 Docling/GROBID。以下数量是解析模型中的条目数，不表示人工逐项核对了论文的每个内容。

LaDe 的 Figure 1 图像存在于官方 HTML 的独立图片段落 `teaser.png`，紧接着的 `<figure>` 只含图注。最初解析器仅搜索 `<figure>` 内部，误报缺图。现已按相邻且仅含图片的段落与图注配对；重新验证后 10 张图均有真实图片资源，已导入的 LaDe 文档也使用同一规则补齐，保留原块 ID 和笔记。该论文附录中的 5 个 prompt SVG 具有可提取的原始文字，按 99 个文字块渲染，避免将 prompt 当成图片。LoRA 官方 HTML 的 8 张图中有 3 张仍只有图注、没有可关联的图像资源；阅读器标明限制并提供该版本 PDF 入口。

来源规则：HTML 路径的正文、MathML、原始 TeX、图表与引用来自 arXiv 官方固定版本；PDF 路径的行间公式和不确定的行内数学段落以原 PDF 裁图为准，Docling/GROBID 提供结构和引用，识别的 TeX 仅供复制、搜索和人工修订。当前无服务端视觉识别密钥，因此 DeepSeek/豆包的真实调用延迟和转写准确率未验证；阅读视图不依赖模型响应。

LaDe 的后续排版检查发现：LaTeXML 列表项自带圆点标记，旧阅读器又添加一次；仅凭标题含有 “Prompt” 会将普通的 Prompt Processing 章节误判为 prompt；表格的跨列、上下边线、单元格中的粗体、公式和引用在旧的纯文本矩阵中丢失。现在使用官方 HTML 的结构化列表项和表格单元格；只有标题为 “Prompts” 或带编号的同名章节使用 prompt 卡片。HTML 公式保留原始 TeX 和 MathML，阅读器优先用 KaTeX 排版可解析的 TeX，失败时回到净化后的 MathML。PDF 路径仍以原图显示公式。已有 LaDe 模型已用保存的官方 HTML 升级上述结构，保留块 ID、原始文本和笔记锚点；这并不等同于直接嵌入外站 HTML 或全站 CSS。

自动测试在完整容器环境下运行 74 项并通过，覆盖无版本链接固定、HTML 安全映射、相邻图片与图注配对、列表/表格/章节分类、缺失 HTML 回退、多用户文档/资源/修订权限。另以临时账号和临时存储调用真实导入 API，使用无版本 LaDe 链接完成解析，确认固定为 v1、返回官方 HTML 阅读模型、图片资源可访问，且另一账号访问文档和图片均返回 404。当前浏览器自动化通道未能连接，已部署页面的真实视觉排版仍需人工检查，尤其是复杂表格、官方 HTML 未提供的图像和 PDF 中未触发数学字体检测的行内公式。
